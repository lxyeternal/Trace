![Trace 一览：概览、轨迹、时间线、项目、逐条记录、专注和报告](docs/tour.zh.gif)

Trace 驻留在菜单栏，自动记录你面前是哪个应用、哪个窗口、哪个文件、哪个网页，以及停留了多久。不需要手动开始计时，也不需要填写任何东西。一天结束时，它告诉你时间花在了哪里，可以细到某一个文件或某一个页面。

## 为什么做 Trace

[Timing](https://timingapp.com) 是 Mac 上自动记录时间这类软件的标杆，但它是付费软件。Trace 是它的免费、开源替代品：同样不需要你动手就能记录一天，不收费，源码公开、可以自己修改，而且除非你主动开启同步，记录不会离开你的 Mac。

## 功能

### 一天的轨迹

每个标签或应用一条轨迹，下面是声音和通话，一眼看出哪些事是同时发生的：一边写代码一边听歌，或者一个挂在后台的会议。再往下，每个打开着的应用各占一条轨迹：窗口在屏幕上时是深色，开着但看不到时是浅色。只有最前面的应用计入记录时长。Trace 只记录哪些应用在播放声音或使用麦克风，不记录播放或说话的内容。没有键鼠操作不等于人不在：正在通话，或者前台应用在播放声音时，时间照常计入。

![一天的并行轨迹，下方是声音、通话和所有打开的应用](docs/screenshots/zh/lanes.png)

### 详细的时间线

按 标签 › 应用 › 文件或网站 › 页面 逐层展开一天的活动。右侧是从上到下的当日时间线：点一个时段，或者在上面拖出任意一段，左侧就只汇总这一段时间。

![带层级汇总和当日时间线的时间线页](docs/screenshots/zh/timeline.png)

### 自动识别项目

Trace 根据文件所在的文件夹判断它属于哪个项目（git 仓库、Swift 包、Obsidian 库，或者“文稿”里的某个文件夹），不用任何设置就能按项目查看时间。

![按项目汇总的时间](docs/screenshots/zh/projects.png)

### 逐条查看每一次停留

切换到“逐条”，可以按顺序查看每一次停留。相关的记录会归到同一个时段里，中途切出去看一眼别的应用不会把时段拆开。选中一条记录，可以看到它的文件路径或网址、当天出现了几次，以及它的标签。

![按时段分组的记录列表和所选记录的详情](docs/screenshots/zh/records.png)

### 自动打标签

内置八个标签：开发、办公、学习、沟通、娱乐、游戏、设计、浏览。它们根据每个应用向 macOS 声明的类别，以及一份常见应用和网站的清单来匹配，装好就能用。你也可以新建自己的标签，按应用、文件路径、网址或窗口标题设置规则，或者给单条记录手动加减标签。规则在读取数据时才计算，所以修改一条规则，全部历史记录都会跟着更新。

|---|---|
| ![预设标签和自定义标签](docs/screenshots/zh/tags.png) | ![规则列表和未标记活动](docs/screenshots/zh/rules.png) |

### 专注、目标和手动时段

“专注”页把三件事放在一起：

- **手动时段。** 点“开始”并选一个标签，从这一刻到你结束，期间做的所有事都算到这个标签上，不管规则怎么判断。适合打游戏、集中学习，或者任何规则猜不出来的事。可以不限时，也可以定时；定时的到点自动结束并提醒你。删除一个时段后，其中的记录恢复原来的标签。
- **目标。** 给标签设每日目标（至少或最多多少时间），用进度环和连续天数来跟踪。
- **这一天有多专注。** 深度工作的时长（连续 25 分钟以上的专注时段）、每小时切换应用的次数、最常把你拉走的是哪些应用。

![专注页：开始一个时段、目标、当天的专注情况](docs/screenshots/zh/focus.png)

### 报告

按周、月、年查看：几句话的回顾，说明和上一周期相比有什么变化；每天的时长（按标签堆叠）；通常在哪些时段活跃；花时间最多的项目、网站和文件。年视图多一张日历，每天一格。任何一段时间都可以导出为 CSV。

![周报告：回顾、每日时长和热力图](docs/screenshots/zh/reports.png)

![全年日历，每天一格](docs/screenshots/zh/year.png)

### 多台 Mac，一份全景

同步是可选功能，默认关闭。在设置里打开**通过 iCloud 同步**，Trace 就会把记录保存到 iCloud 云盘里的 `Trace` 文件夹：不需要任何设置，登录同一个 iCloud 账号并打开这个开关的 Mac 会自动加入。每台 Mac 把自己的记录写进去，并读取其他 Mac 的记录。也可以改用其他会同步的文件夹（Dropbox、网络硬盘等）。标签和规则是共用的，可以合在一起看，也可以单独看某一台。文件是纯文本，所以这个文件夹同时也是一份备份。

### 原生的 Mac 体验

使用 SwiftUI 编写，支持浅色、深色和跟随系统；界面有简体中文、英文和俄文，切换后立即生效，不需要重启；支持登录时自动启动。菜单栏面板显示今天的总时长、最前面的应用，以及同时在发生的事：通话、声音、屏幕上的窗口和后台打开的应用。关掉窗口后，Trace 继续在菜单栏里记录。

## 隐私

- **默认只存本机。** 所有数据保存在一个 SQLite 文件里：`~/Library/Application Support/Trace/trace.sqlite`。Trace 不联网，也没有账号。
- **只有你开启才会同步。** 设置了同步文件夹后，记录会同时以可读文件的形式写进去，由同步这个文件夹的服务负责传输。能打开这个文件夹的人都能读到这些记录。关闭同步后，Trace 不再往里写。
- **不记录按键，不截屏。** Trace 只读取前台应用的名称，并通过 macOS 的辅助功能接口读取当前窗口的标题、文档路径和页面地址，除此之外什么都不读。
- **网址会去掉敏感部分。** 保存之前会去掉查询参数、锚点和账号密码。
- **记录什么由你决定。** 窗口标题、文件路径、网址、声音和通话、打开的应用列表可以分别关闭，任何应用都可以完全排除。
- **数据属于你。** 随时可以在设置里导出为 CSV，或者全部清除。

## 安装

需要 macOS 14 或更高版本，支持 Apple 芯片和 Intel。

1. 从[最新发布](https://github.com/lxyeternal/Trace/releases/latest)下载 `.dmg` 文件。
2. 打开它，把 Trace 拖到“应用程序”文件夹。
3. 启动 Trace。它会请求**辅助功能**权限（系统设置 › 隐私与安全性 › 辅助功能）。不授权也能记录前台是哪个应用，但读不到窗口标题、文件路径和网址。

发布的安装包使用 Developer ID 证书签名，并经过 Apple 公证，打开时不会出现安全警告。

## 从源码构建

需要 Xcode 16 或更高版本。

```bash
git clone https://github.com/lxyeternal/Trace.git
cd Trace
scripts/bundle.sh
open build/Trace.app
```

默认构建使用临时签名，所以每次重新构建后，macOS 都会要求重新授予辅助功能权限。想避免这一点，可以把你的一个签名证书的名称（用 `security find-identity -v -p codesigning` 查看）写进仓库根目录下名为 `.codesign-identity` 的文件，这个文件已被 git 忽略。

常用命令：

| 命令 | 作用 |
|---|---|
| `swift test` | 运行核心库的单元测试。 |
| `open -n build/Trace.app --args --demo` | 用虚构的数据打开 Trace，不记录任何真实活动。 |
| `scripts/release.sh` | 构建通用版本的应用，并打包成 DMG 和 zip。 |
| `swift scripts/make-icon.swift` | 重新绘制应用图标。 |

## 工作原理

| 部分 | 位置 | 作用 |
|---|---|---|
| 采集 | `Sources/Trace/Capture` | 每两秒从 `NSWorkspace` 读取前台应用，通过辅助功能接口读取当前窗口，从 `CGEventSource` 读取空闲时间，从 Core Audio 读取哪些应用在播放声音或使用麦克风。每十秒还会从窗口列表读取哪些应用开着、窗口是否在屏幕上（只读归属和位置，不读标题和内容）。 |
| 存储 | `Sources/TraceCore/EventStore.swift` | 通过 [GRDB](https://github.com/groue/GRDB.swift) 使用 SQLite。连续相同的采样会延长同一条记录，所以每次停留只有一行。空闲时间不保存，表现为记录之间的空隙。 |
| 标签 | `Sources/TraceCore/Tagging.swift` | 规则可以匹配应用、应用类别、文件路径、网址或窗口标题。对单条记录手动加减的标签优先于规则。 |
| 同步 | `Sources/TraceCore/SyncEngine.swift` | 每台 Mac 在同步文件夹里自己的子目录下按天写文件，并读取其他 Mac 的文件，所以两台 Mac 不会修改同一个文件。标签和规则以最近一次修改为准。 |
| 分析 | `Sources/TraceCore/Analyzer.swift`、`Insights.swift` | 每日汇总、时段划分、层级汇总、轨迹、专注度、项目、报告、回顾和 CSV 导出。 |
| 界面 | `Sources/Trace/Views` | SwiftUI。颜色和通用控件在 `Theme.swift` 里。 |

`TraceCore` 不包含界面，有单元测试覆盖；应用部分在它之上加入采集和界面。

## 添加一种语言

把 `Resources/zh-Hans.lproj` 复制为 `Resources/<语言代码>.lproj`，翻译每一行等号右边的内容，然后把语言代码加到 `Support/Info.plist` 的 `CFBundleLocalizations` 和 `Sources/Trace/Localization.swift` 的 `AppLanguage` 里。英文原文就是键，其他地方不需要改。

## 已知限制

- 不碰键盘和鼠标看无声视频或长时间阅读，超过空闲判定时长后会被记为离开；正在通话或前台应用有声音时不会；后台音乐是否算在场可以在设置里选择。
- 声音和通话是根据哪个应用在用扬声器或麦克风来判断的。一直占用麦克风但并非通话的应用（比如语音输入工具）会被当成通话，可以在设置里排除它。
- 无法识别浏览器的无痕窗口，会和普通窗口一样记录。如果介意，可以排除该浏览器，或者关闭网址记录。
- 能否读到页面地址，取决于浏览器向辅助功能接口暴露了什么。Safari 和基于 Chromium 的浏览器（Chrome、Edge、Arc、Brave）可以读到；其他浏览器可能只有窗口标题。

- 开启同步后，不同 Mac 之间的时间不会去重：两台 Mac 同时在用（比如通过远程桌面），两边都会计入，时间线上并排显示。手动给单条记录加的标签只保留在添加它的那台 Mac 上。
